# Search Modes

検索モードは、質問に対して「特定記事を優先するか」「Wikipedia全体を横断するか」を切り替えるためのものです。

## `article_focus` --- 記事特定優先

推奨デフォルトです。

質問の先頭からWikipedia記事タイトルを検出し、記事が特定できればその単一記事のチャンクだけを検索します。

質問の残りを記事内クエリとして使い、ベクトル検索と文字列一致で関係する箇所を順位付けします。

記事を特定できない場合は広域検索へフォールバックします。

向いている例:

``` text
ファイナルファンタジーXIVのストーリーについて教えて
Fallout 3の開発経緯
```

対象が一つに定まっている質問では、まずこのモードを使用します。

## `auto` --- 自動判別

タイトル一致と全体検索を組み合わせるハイブリッドモードです。

記事タイトルを確定できた場合はその記事を深掘りし、確定できない場合はベクトル類似度とタイトルFTS等を組み合わせてWikipedia全体から検索します。

一般的な質問で、記事を一つに限定すべきか事前に分からない場合に使います。

## `legacy_auto` --- 旧互換

`article_focus`
による「質問先頭からの記事名抽出」を行わず、従来型のauto検索を実行する比較・検証用モードです。

新方式で意図しない記事にマッチする場合の比較や、検索アルゴリズム変更前後の挙動確認に使用します。

通常利用では `article_focus` または `auto` を優先します。

## `strict` --- 厳格検索

質問に対応する記事タイトルが存在することを必須条件とします。

タイトルを確定できなければ結果を返さず、似ているだけの別記事を無理に提示しません。

向いている用途:

-   固有名詞の事実確認
-   対象記事が存在すると分かっている場合
-   関係ない類似記事を混ぜたくない場合

## `balanced` --- 本命 + 関連記事

本命の記事を中心にしつつ、関連する別記事の情報も検索結果へ含めます。

単一記事だけでは背景が不足する質問や、対象と周辺知識を一緒に扱いたい場合に向いています。

## `discovery` --- 横断探索

タイトル一致による単一記事への拘束を弱め、ベクトル類似度を中心にWikipedia全体から関連チャンクを集めます。

同一記事から結果が偏りすぎないよう制限を設け、複数記事を横断する検索を想定します。

向いている例:

``` text
AとBの共通点
1980年代に流行した○○
特定の記事名が分からない概念検索
```

## 使い分け

  モード            検索範囲              主な用途
  ----------------- --------------------- ----------------------------
  `article_focus`   特定記事 → 記事内     単一対象について詳しく聞く
  `auto`            記事特定 + 全体検索   一般的な質問
  `legacy_auto`     旧auto                比較・検証
  `strict`          確定記事のみ          厳密な固有名詞検索
  `balanced`        本命 + 関連記事       本文と周辺知識
  `discovery`       Wikipedia全体         横断・概念検索

検索モードの内部設計やタイトル一致の詳細は `SEARCH_DESIGN.md`
を参照してください。
